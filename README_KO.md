## 🎬 실제 동작 확인

> 🎥 **데모 영상 준비 중!** 이 리포지토리에 Star를 눌러 출시 알림을 받으세요.

<!-- ![VibeSmith Demo](https://vibesmith.com/images/demo.gif) -->

**우리가 해결하는 문제:**

❌ **VibeSmith 이전:**
- "50개 이상의 스킬이 있는데 뭐가 활성화되어 있는지 모르겠어요"
- "3개 프로젝트에 같은 이름의 스킬이 있어서 혼란스러워요"
- "AI가 잘못된 컨텍스트를 사용해서 토큰을 낭비해요"
- "순환 참조 때문에 워크플로우가 망가져요"

✅ **VibeSmith 이후:**
- **하나의 대시보드, 완벽한 제어** - 모든 스킬을 한눈에
- **스마트 충돌 감지** - 중복을 자동으로 찾아줌
- **컨텍스트 최적화** - 토큰 30-50% 절약
- **종속성 그래프** - 관계를 즉시 시각화

## ✨ 주요 기능

### 📊 종속성 그래프
<!-- ![Dependency Graph](https://vibesmith.com/images/dependency-graph.png) -->
> 🖼️ 스크린샷 준비 중

**모든 컴포넌트 간 관계를 시각화:**
- 순환 참조 자동 감지
- 스킬 간 종속성 확인
- 프로젝트, 타입, 위험도별 필터링
- 노드 클릭으로 상세 정보 확인

---

### 🔍 충돌 감지
<!-- ![Conflict Detection](https://vibesmith.com/images/conflict-detection.png) -->
> 🖼️ 스크린샷 준비 중

**중복되거나 겹치는 스킬을 자동으로 찾아줌:**
- 글로벌 vs 프로젝트 스킬 충돌
- 여러 프로젝트에 걸친 동일 이름 컴포넌트
- 원클릭 해결 (비활성화, 이름 변경, 삭제)
- 스마트 알림으로 AI 혼란 방지

---

### 📈 컨텍스트 최적화
<!-- ![Context Optimizer](https://vibesmith.com/images/context-optimizer.png) -->
> 🖼️ 스크린샷 준비 중

**토큰 사용량 30-50% 절감:**
- 너무 큰 스킬 분석
- 기술 스택 불일치 감지 (React 프로젝트에 Python 스킬)
- 사용하지 않는 글로벌 스킬 찾기
- 원클릭 수정으로 실행 가능한 제안

---

### 🎯 스마트 On/Off 토글
<!-- ![Smart Toggle](https://vibesmith.com/images/smart-toggle.png) -->
> 🖼️ 스크린샷 준비 중

**프로젝트별로 필요한 것만 활성화:**
- 타입이나 태그별 일괄 활성화/비활성화
- 프로젝트별 프로파일
- 시각적 상태 표시
- 파일 변경 없이 즉시 적용

---

### 🔍 강력한 검색 & 필터
- 모든 컴포넌트에 대한 퍼지 검색
- 타입, 프로젝트, 태그, 상태별 필터
- 이름, 날짜, 사용량별 정렬
- 키보드 단축키 (Cmd+K로 빠른 접근)

---

### 🎨 아름답고 현대적인 UI
- 다크/라이트 모드
- 반응형 디자인
- 직관적인 네비게이션
- 접근성 우선 (WCAG 2.1 AA)

## 🤝 기여하기

이 **커뮤니티 리포지토리**는 다음을 위한 것입니다:
- 📚 문서 개선
- 🔌 플러그인 공유
- 🎨 테마 개발
- 🐛 버그 리포트
- 💡 기능 요청

**참고:** VibeSmith 앱 소스 코드는 **프로프라이어터리**(비공개)입니다.

### 기여 방법
1. 🍴 이 리포지토리를 Fork
2. 🌿 기능 브랜치 생성: `git checkout -b feature/amazing-plugin`
3. ✍️ 변경사항 작성
4. 📝 커밋: `git commit -m '멋진 플러그인 추가'`
5. 🚀 푸시: `git push origin feature/amazing-plugin`
6. 🎉 Pull Request 열기

자세한 가이드라인은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참조하세요.
