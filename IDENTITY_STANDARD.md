# Identity Standard Rule

This repository must use only the following identity values.

## Allowlist

- GitHub Handle: `aroido-bigcat`, `aroido-kkachi`
- Email: `bigcat@aroido.com`, `kkachi@aroido.com`
- Nickname: `bigcat`, `kkachi`

## Denylist (examples)

- Real names, old account names, old emails, old nicknames
- Examples: `aroido-bigcat`, `aroido-kkachi`, `aroido-kkachi`, `@aroido-bigcat`, `aroido-kkachi`, `bigcat@aroido.com`

## Scope

- Docs, templates, scripts, issue/PR examples, release notes

## Enforcement

- New/updated content must use only allowlist values
- If a denylist value is found, replace it immediately with allowlist values
