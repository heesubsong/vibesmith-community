# Contributing to VibeSmith

Thank you for your interest in contributing! 🎉

## 🤝 How to Contribute

## 🔐 Identity Standard

Before opening a PR, follow [IDENTITY_STANDARD.md](IDENTITY_STANDARD.md).
Only the allowlisted handles/emails/nicknames are permitted in this repository.

### Documentation

- Fix typos or improve clarity
- Add examples or tutorials
- Translate documentation

### Plugins

- Create new plugins
- Improve existing plugins
- Share your use cases

### Bug Reports

- Use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md)
- Provide detailed reproduction steps
- Include screenshots if possible

### Feature Requests

- Use the [feature request template](.github/ISSUE_TEMPLATE/feature_request.md)
- Explain your use case
- Discuss in [Discussions](https://github.com/aroido/vibesmith-community/discussions) first

## 💬 Questions?

Join our [Discord](https://discord.gg/vibesmith) or start a [Discussion](https://github.com/aroido/vibesmith-community/discussions).
