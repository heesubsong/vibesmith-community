## What is VibeSmith?

**VibeSmith** is a desktop application for efficiently managing AI coding agent components (Cursor, Claude Code).

## Key Features

### Unified Management
- **Skills**: AI agent capabilities
- **Agents**: Automated subagents
- **Commands**: Slash commands
- **Hooks**: Git hooks
- **Rules**: Project rules

### Visualization
- **Dependency Graph**: Interactive visualization of component relationships
- **Statistics Dashboard**: Complete workspace overview at a glance
- **Search & Filter**: Quickly find any component

### Synchronization
- **Local ↔ Global**: Manage project-specific and global components
- **Auto Scan**: Detect file changes and auto-update
- **Conflict Resolution**: Automatically detect and resolve duplicate components

## Who is it for?

VibeSmith is designed for:

### Developers
- Using Cursor or Claude Code
- Looking to automate workflows with AI agents
- Reusing skills across multiple projects

### Teams
- Sharing AI agent components across the team
- Managing project-specific coding standards
- Maintaining consistent development workflows

### Projects
- Large-scale projects with complex dependencies
- Projects utilizing multiple AI skills
- Projects requiring high levels of automation

## System Requirements

## Operating System

- **macOS**: 10.15 (Catalina) or later
- **Windows**: 10 or later
- **Linux**: Ubuntu 20.04 or later (or equivalent)

## Hardware

- **Memory**: 4GB RAM minimum (8GB+ recommended)
- **Storage**: 500MB minimum
- **Display**: 1280x720 or higher

## Software

- **Required**: Cursor or Claude Code
- **Optional**: Git (for version control features)
