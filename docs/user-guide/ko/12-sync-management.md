# 동기화 관리

> 📝 이 문서는 자동으로 생성되었습니다. 내용이 부정확하거나 누락된 부분이 있다면 [Issue](https://github.com/heesubsong/vibesmith-community/issues)로 제보해주세요.

## 동기화 설정

![동기화 설정](images/sync-01-settings.png)

**설정** > **동기화**에서 로컬과 글로벌 컴포넌트 동기화를 관리할 수 있습니다.

## 로컬 vs 글로벌

### 로컬 컴포넌트
- **위치**: `.cursor/`, `.claude/`
- **범위**: 현재 프로젝트만
- **용도**: 프로젝트 특화 컴포넌트

### 글로벌 컴포넌트
- **위치**: `~/.cursor/`, `~/.claude/`
- **범위**: 모든 프로젝트
- **용도**: 재사용 가능한 범용 컴포넌트

## 동기화 방향

- **로컬 → 글로벌**: 프로젝트 스킬을 전역으로 승격
- **글로벌 → 로컬**: 전역 스킬을 프로젝트로 복사
- **양방향**: 자동 동기화 (변경 감지)

## 수동 동기화

![수동 동기화](images/sync-02-manual.png)

![수동 동기화 데모](gifs/sync-demo.gif)

**동기화** 버튼을 클릭하여 수동으로 동기화를 실행할 수 있습니다.

## 동기화 프로세스

1. **변경 감지**: 로컬과 글로벌 차이 확인
2. **충돌 검사**: 중복 컴포넌트 확인
3. **미리보기**: 동기화될 항목 표시
4. **실행**: 확인 후 동기화

## 동기화 옵션

- **덮어쓰기**: 기존 파일 덮어쓰기
- **병합**: 내용 병합
- **건너뛰기**: 충돌 항목 건너뛰기
- **백업**: 기존 파일 백업 후 동기화

## 충돌 해결

![충돌 해결](images/sync-03-conflicts.png)

동기화 중 충돌이 발견되면 **충돌 해결** 창이 나타납니다.

## 충돌 유형

### 1. 이름 충돌
- 같은 이름의 컴포넌트가 로컬과 글로벌에 모두 존재
- **해결**: 한쪽 이름 변경 또는 우선순위 설정

### 2. 내용 충돌
- 같은 컴포넌트가 로컬과 글로벌에서 다르게 수정됨
- **해결**: 수동 병합 또는 한쪽 선택

### 3. 의존성 충돌
- 의존성 체인이 순환 참조
- **해결**: 의존성 재구성

## 충돌 해결 전략

- **로컬 우선**: 로컬 변경사항 유지
- **글로벌 우선**: 글로벌 변경사항 적용
- **수동 병합**: 직접 선택
- **백업 후 덮어쓰기**: 안전한 선택

## 자동 동기화

![자동 동기화](images/sync-04-auto.png)

**설정** > **동기화** > **자동 동기화**를 켜면 파일 변경 시 자동으로 동기화됩니다.

## 자동 동기화 동작

- **파일 감시**: 로컬/글로벌 디렉토리 모니터링
- **변경 감지**: 파일 생성/수정/삭제 감지
- **자동 동기화**: 설정된 규칙에 따라 자동 동기화
- **충돌 알림**: 충돌 발생 시 알림

## 동기화 규칙

- **로컬 우선**: 로컬 변경사항을 글로벌로 자동 푸시
- **글로벌 우선**: 글로벌 변경사항을 로컬로 자동 풀
- **양방향**: 최신 변경사항 기준
- **수동 확인**: 충돌 시 사용자 확인 요청

## 동기화 주기

- **즉시**: 파일 변경 시 즉시 (권장하지 않음)
- **5분**: 5분마다 (기본)
- **10분**: 10분마다
- **수동**: 자동 동기화 끄기

### ⚠️ 주의사항

⚠️ 자동 동기화 활성화 시 의도치 않은 덮어쓰기가 발생할 수 있습니다.
⚠️ 중요한 변경 전에는 백업을 권장합니다.
⚠️ 네트워크 드라이브에서는 자동 동기화가 느릴 수 있습니다.
