# 훅 관리

## 훅 페이지 이동

![훅 페이지 이동](images/hooks-01-list.png)

왼쪽 사이드바의 **Components** > **Hooks**를 클릭하면 모든 Git 훅 목록을 볼 수 있습니다.

Git 훅은 커밋, 푸시 등의 Git 작업 시 자동으로 실행되는 스크립트입니다.

## 주요 Git 훅

- **pre-commit**: 커밋 전 실행 (린트, 포맷 검사)
- **commit-msg**: 커밋 메시지 검증
- **pre-push**: 푸시 전 실행 (테스트 실행)
- **post-commit**: 커밋 후 실행 (알림 등)

### 💡 유용한 팁

💡 훅은 Git 워크플로우를 자동화하는 강력한 도구입니다.
💡 pre-commit 훅으로 코드 품질을 자동 검사할 수 있습니다.
💡 훅이 실패하면 Git 작업이 중단됩니다.

## 새 훅 생성

![새 훅 생성](images/hooks-02-new-modal.png)

**+ New Hook** 버튼을 클릭하면 훅 생성 모달이 나타납니다.

## 훅 설정

1. **훅 타입 선택**: pre-commit, commit-msg, pre-push 등
2. **스크립트 작성**: 실행할 명령어 또는 스크립트
3. **실행 조건**: 특정 파일 패턴 등

## 예시: pre-commit 린트 검사

```bash
#!/bin/bash
# 린트 검사
npm run lint

# 실패 시 커밋 중단
if [ $? -ne 0 ]; then
  echo "❌ 린트 검사 실패. 커밋이 중단되었습니다."
  exit 1
fi
```

### ⚠️ 주의사항

⚠️ 훅 스크립트는 반드시 실행 권한이 있어야 합니다.
⚠️ 훅이 실패하면 Git 작업이 중단되므로 신중하게 작성하세요.
⚠️ 너무 복잡한 훅은 작업 속도를 느리게 만들 수 있습니다.

## 훅 활성화/비활성화

![훅 활성화/비활성화](images/hooks-03-toggle.png)

훅 카드의 토글 스위치로 훅을 활성화하거나 비활성화할 수 있습니다.

## 활성화 vs 비활성화

- **활성화**: 훅이 Git 작업 시 자동 실행
- **비활성화**: 훅이 실행되지 않음 (일시적으로 끄기)

## 사용 시나리오

**개발 중**: 빠른 테스트를 위해 일시적으로 비활성화
**릴리즈 전**: 모든 훅을 활성화하여 품질 검증

토글은 즉시 반영됩니다.
