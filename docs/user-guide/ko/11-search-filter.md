## 전역 검색

![전역 검색](images/search-01-global.png)

![전역 검색 데모](gifs/search-demo.gif)

상단 헤더의 **검색창** 또는 **Cmd+K** (Mac) / **Ctrl+K** (Windows)로 전역 검색을 열 수 있습니다.

## 검색 범위

- **이름**: 컴포넌트 이름
- **설명**: 컴포넌트 설명
- **태그**: 태그
- **경로**: 파일 경로
- **내용**: SKILL.md, AGENT.md 등의 내용

## 검색 모드

- **퍼지 검색**: 오타를 허용 (기본)
- **정확한 검색**: 따옴표로 감싸기 (`"exact"`)
- **정규식 검색**: 슬래시로 감싸기 (`/regex/`)

## 키보드 단축키

- **Cmd+K / Ctrl+K**: 검색창 열기
- **↑ ↓**: 결과 이동
- **Enter**: 선택한 항목 열기
- **Cmd+Enter**: 새 탭에서 열기
- **Esc**: 검색창 닫기

## 고급 필터

![고급 필터](images/search-02-filters.png)

**필터** 버튼을 클릭하면 고급 필터 옵션이 나타납니다.

## 필터 옵션

### 타입별 필터
- Skills
- Agents
- Commands
- Hooks
- Rules

### 경로별 필터
- 로컬 (.cursor/)
- 글로벌 (~/.cursor/)

### 태그별 필터
- 여러 태그 선택 가능
- AND/OR 조건 선택

### 날짜별 필터
- 최근 수정일
- 생성일
- 최근 1주일, 1개월, 3개월

## 정렬

- **이름**: 알파벳 순
- **최근 수정**: 최신순
- **사용 빈도**: 많이 사용된 순
- **의존성**: 의존성 많은 순

## 저장된 검색

![저장된 검색](images/search-03-saved.png)

자주 사용하는 검색 조건을 저장할 수 있습니다.

## 검색 저장

1. 검색 조건 설정
2. **저장** 버튼 클릭
3. 검색 이름 입력
4. **확인**

## 저장된 검색 사용

- 검색창에서 **저장된 검색** 탭 클릭
- 원하는 검색 선택
- 즉시 적용

## 예시

- "내가 만든 스킬": 로컬 스킬 + 최근 1주일
- "React 관련": 태그에 react 포함
- "테스트 스킬": 이름에 test 포함
