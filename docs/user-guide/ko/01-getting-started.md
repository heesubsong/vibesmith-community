## VibeSmith란?

**VibeSmith**는 AI 코딩 에이전트(Cursor, Claude Code)의 구성요소를 효율적으로 관리하는 데스크톱 애플리케이션입니다.

## 주요 기능

### 통합 관리
- **Skills**: AI 에이전트 스킬
- **Agents**: 자동화된 서브에이전트
- **Commands**: 슬래시 명령어
- **Hooks**: Git 훅
- **Rules**: 프로젝트 규칙

### 시각화
- **의존성 그래프**: 컴포넌트 간 관계를 인터랙티브 그래프로 표시
- **통계 대시보드**: 전체 현황을 한눈에 파악
- **검색 및 필터**: 원하는 컴포넌트를 빠르게 찾기

### 동기화
- **로컬 ↔ 글로벌**: 프로젝트별/전역 컴포넌트 관리
- **자동 스캔**: 파일 변경 감지 및 자동 업데이트
- **충돌 해결**: 중복 컴포넌트 자동 감지 및 관리

## 누구를 위한 도구인가요?

VibeSmith는 다음과 같은 분들에게 적합합니다:

### 개발자
- Cursor 또는 Claude Code를 사용하는 개발자
- AI 에이전트를 활용한 자동화를 원하는 개발자
- 여러 프로젝트에서 스킬을 재사용하고 싶은 개발자

### 팀
- AI 에이전트 구성요소를 팀원과 공유하고 싶은 팀
- 프로젝트별 코딩 규칙을 관리하고 싶은 팀
- 일관된 워크플로우를 유지하고 싶은 팀

### 프로젝트
- 복잡한 의존성을 가진 대규모 프로젝트
- 다양한 AI 스킬을 사용하는 프로젝트
- 자동화가 중요한 프로젝트

## 운영체제

- **macOS**: 10.15 (Catalina) 이상
- **Windows**: 10 이상
- **Linux**: Ubuntu 20.04 이상 (또는 동등한 배포판)

## 하드웨어

- **메모리**: 최소 4GB RAM (권장 8GB 이상)
- **저장공간**: 최소 500MB
- **디스플레이**: 1280x720 이상
