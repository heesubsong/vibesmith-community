# VibeSmith

> AI Agent Components Manager for Cursor & Claude Code

Manage your AI coding agent's skills, agents, commands, and hooks like a pro.

![Hero](https://vibesmith.com/images/hero.png)

## ✨ Features

- 🎯 **Unified Management** - Skills, Agents, Commands in one place
- 📊 **Dependency Graph** - Visualize component relationships
- 🔍 **Smart Search** - Find components instantly
- 🎨 **Beautiful UI** - Modern, intuitive interface
- 🔄 **Auto Sync** - Keep contexts in sync
- 🤝 **Team Collaboration** - Share with your team (Pro)
