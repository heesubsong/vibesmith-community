## ✨ Key Features

### 📊 Dependency Graph
<!-- ![Dependency Graph](https://vibesmith.com/images/dependency-graph.png) -->
> 🖼️ Screenshot Coming Soon

**Visualize relationships between all your components:**
- Detect circular dependencies automatically
- See which skills depend on each other
- Filter by project, type, or risk level
- Click nodes to see detailed info

---

### 🔍 Conflict Detection
<!-- ![Conflict Detection](https://vibesmith.com/images/conflict-detection.png) -->
> 🖼️ Screenshot Coming Soon

**Find duplicate and overlapping skills:**
- Global vs Project skill conflicts
- Same-name components across projects
- One-click resolution (disable, rename, or delete)
- Prevent AI confusion with smart alerts

---

### 📈 Context Optimizer
<!-- ![Context Optimizer](https://vibesmith.com/images/context-optimizer.png) -->
> 🖼️ Screenshot Coming Soon

**Reduce token usage by 30-50%:**
- Analyze which skills are too large
- Detect tech mismatches (Python skill in React project)
- Find unused global skills
- Get actionable suggestions with one-click fixes

---

### 🎯 Smart On/Off Toggle
<!-- ![Smart Toggle](https://vibesmith.com/images/smart-toggle.png) -->
> 🖼️ Screenshot Coming Soon

**Enable only what you need, per project:**
- Bulk enable/disable by type or tag
- Project-specific profiles
- Visual status indicators
- Instant activation without file changes

---

### 🔍 Powerful Search & Filter
- Fuzzy search across all components
- Filter by type, project, tag, or status
- Sort by name, date, or usage
- Keyboard shortcuts (Cmd+K for quick access)

---

### 🎨 Beautiful, Modern UI
- Dark/Light mode
- Responsive design
- Intuitive navigation
- Accessibility-first (WCAG 2.1 AA)
