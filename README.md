## 🎯 What is VibeSmith?

VibeSmith is a desktop application for efficiently managing AI coding agent components (Cursor, Claude Code).

### Key Features
- **Unified Management**: Skills, Agents, Commands, Hooks, Rules
- **Visualization**: Interactive dependency graphs
- **Synchronization**: Local ↔ Global component sync

## 📥 Installation

### macOS (Homebrew)
```bash
brew tap heesubsong/vibesmith
brew install --cask vibesmith
```

### Other Platforms
Download from [GitHub Releases](https://github.com/heesubsong/vibesmith/releases)
